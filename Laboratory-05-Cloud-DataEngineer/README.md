# Laboratory 05 – The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I learned about cloud storage and deployed an S3-compatible object storage server using MinIO. I used Docker in the KillerCoda Ubuntu Playground to run MinIO, accessed its web console, created a storage bucket, and uploaded a sample file.

## Objectives

- Differentiate Block Storage, File Storage, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through a web browser.
- Create an object storage bucket.
- Upload a file to the bucket.
- Document cloud storage operations using Markdown.
- Practice using Linux and Docker commands.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Web Browser
- Markdown

## Skills Learned

- Understanding different types of cloud storage.
- Using Docker to deploy a cloud storage service.
- Working with MinIO and object storage.
- Using ports to access web-based cloud services.
- Creating buckets and uploading objects.
- Using Linux command-line commands.
- Creating and organizing Markdown documentation.
- Maintaining a GitHub cloud computing portfolio.
