# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, compute resources are one of the most important components of cloud infrastructure because they provide the processing power needed to run applications and services. Without sufficient CPU and memory, applications cannot perform their tasks efficiently. However, compute also depends on storage, networking, and the operating system to function properly.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for servers and applications. Its command-line tools also make it easier for cloud engineers to monitor resources, manage files, inspect networks, and troubleshoot systems. The KillerCoda activity helped me see how Linux commands can be used to investigate an actual cloud environment.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the resources, configurations, and design decisions involved in an infrastructure project. Proper documentation helps engineers understand the system before deployment and makes troubleshooting and future maintenance easier.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as `lscpu`, `free`, `df`, `findmnt`, `hostname`, and `hostname -I`. I also improved my Markdown documentation skills and learned how to compare equivalent services from AWS, Microsoft Azure, and Google Cloud. Creating the cloud architecture diagram also helped me understand how different infrastructure components connect with each other.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized and informative after completing this mission. I added a dedicated laboratory folder containing technical reports, cloud provider comparisons, documentation, reflection, screenshots, and an infrastructure diagram. This makes my portfolio a better record of the cloud computing skills and activities I have completed.
