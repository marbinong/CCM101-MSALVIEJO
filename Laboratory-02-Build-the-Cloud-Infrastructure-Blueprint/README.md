# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focused on investigating the infrastructure components that support cloud computing. Using the KillerCoda Linux environment, I examined the server's compute, storage, networking, and operating system resources. I also researched the infrastructure services provided by AWS, Microsoft Azure, and Google Cloud.

## Objectives

- Explain the major components of cloud infrastructure.
- Investigate hardware and software resources in a Linux environment.
- Identify compute, storage, networking, and operating system resources.
- Compare AWS, Microsoft Azure, and Google Cloud services.
- Create a simple cloud infrastructure architecture.
- Practice technical documentation using Markdown.
- Improve the GitHub Cloud Computing Portfolio.

## Cloud Infrastructure Components

The major infrastructure components investigated were:

1. Compute Resources
2. Storage Resources
3. Networking Resources
4. Operating System

These components work together to provide the resources needed to operate cloud-based applications and services.
