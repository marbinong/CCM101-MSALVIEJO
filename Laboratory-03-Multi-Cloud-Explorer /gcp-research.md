# Google Cloud Platform Research

## Brief Overview

**Google Cloud Platform (GCP), commonly called Google Cloud**, is Google's public cloud platform.

It provides services for compute, storage, networking, databases, analytics, artificial intelligence, machine learning, containers, and application development.

Google Cloud has strong capabilities in data processing, artificial intelligence, machine learning, distributed systems, and Kubernetes.

## Global Infrastructure

Google Cloud provides a global infrastructure organized into regions and zones.

Regions are geographic locations, while zones are isolated locations within regions.

Organizations can use regions and zones to deploy applications closer to users and improve availability.

Official source:

https://cloud.google.com/about/locations/

## Cloud Management Console

The **Google Cloud Console** is a browser-based interface used to manage Google Cloud projects and resources.

It can be used to create and manage virtual machines, storage buckets, databases, networks, Kubernetes clusters, identities, and other services.

## Four Core Services

### 1. Compute Engine

Compute Engine provides configurable virtual machines and infrastructure for running applications and workloads.

### 2. Cloud Storage

Cloud Storage is a scalable object storage service that stores data in buckets.

### 3. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service for deploying and operating containerized applications.

### 4. Cloud SQL

Cloud SQL is a fully managed relational database service supporting MySQL, PostgreSQL, and SQL Server.

## Three Advantages

1. **Strong AI and data capabilities** – Google Cloud provides strong services for artificial intelligence, machine learning, analytics, and data processing.
2. **Kubernetes expertise** – Google developed Kubernetes and provides GKE as a managed Kubernetes platform.
3. **Global network** – Google Cloud provides global infrastructure for applications requiring worldwide availability and low latency.

## Typical Enterprise Use Cases

Google Cloud is commonly used for:

- Artificial intelligence and machine learning
- Big data and analytics
- Kubernetes and container platforms
- Global web applications
- Data warehouses
- Data lakes
- Application modernization
- E-commerce systems
- High-performance computing
