
# AWS Research

## Brief Overview

**Amazon Web Services (AWS)** is a public cloud platform that provides computing, storage, databases, networking, security, analytics, artificial intelligence, and many other services.

AWS launched in 2006 and has grown into one of the largest cloud platforms in the world. It is widely used by startups, enterprises, government organizations, and developers.

## Global Infrastructure

AWS organizes its infrastructure into **Regions** and **Availability Zones (AZs)**.

A Region is a separate geographic area, while Availability Zones are isolated locations inside a Region. Organizations can deploy resources across multiple Availability Zones to improve availability and reliability.

AWS also provides additional infrastructure options such as Local Zones and Wavelength Zones for workloads that require lower latency.

Official source:

https://aws.amazon.com/about-aws/global-infrastructure/

## Cloud Management Console

The **AWS Management Console** is a browser-based interface used to create, configure, monitor, and manage AWS resources.

Users can access services such as EC2, S3, RDS, IAM, and VPC through the console.

Official source:

https://aws.amazon.com/console/

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable computing capacity through virtual servers. It can host websites, applications, databases, and development environments.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve files and other data at scale.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking capabilities for AWS resources. It allows organizations to create isolated networks and control IP addressing, routing, and security.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls authentication and authorization for AWS resources. It allows administrators to manage users, roles, policies, and permissions.

## Three Advantages

1. **Broad service selection** – AWS provides services for computing, storage, databases, networking, security, analytics, AI, and many other areas.
2. **Global infrastructure** – AWS has infrastructure in many geographic locations around the world.
3. **Scalability** – AWS services can scale according to workload requirements.

## Typical Enterprise Use Cases

AWS is commonly used for:

- Web and mobile application hosting
- E-commerce platforms
- Data backup and disaster recovery
- Enterprise databases
- Big data and analytics
- Artificial intelligence and machine learning
- Containerized applications
- Global applications
