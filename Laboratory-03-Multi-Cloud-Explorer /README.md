# Laboratory 03 – Multi-Cloud Explorer

**Course:** CCM101 – Cloud Computing  
**Laboratory Activity:** 3 – Mission 3: Become a Multi-Cloud Explorer

## Mission Overview

This laboratory activity explores three major public cloud providers: **Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP)**. The activity compares their infrastructure, management consoles, core services, advantages, and common enterprise use cases. It also applies the comparison to different client scenarios and examines how a Linux server could be migrated to the cloud.
