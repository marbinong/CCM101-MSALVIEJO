# Reflection

## My Reflection on the Multi-Cloud Explorer Activity

This laboratory activity helped me understand that choosing a cloud provider is not only about popularity. AWS, Microsoft Azure, and Google Cloud all provide similar basic services, but each platform has different strengths.

I learned that AWS is known for its broad range of services and global infrastructure. Azure is a strong choice for organizations that already use Microsoft technologies because of its integration with Windows Server, Microsoft 365, and Microsoft Entra ID. Google Cloud is especially strong for artificial intelligence, data analytics, and Kubernetes.

The client scenarios also showed me that the recommended cloud platform should depend on the actual business requirement. For example, Azure is a logical choice for a university with an existing Microsoft environment, while Google Cloud is a strong choice for an AI research company.

The Linux investigation also helped connect Linux skills with cloud computing. The Ubuntu server information can be used to identify an appropriate virtual machine configuration in AWS, Azure, or Google Cloud.

Overall, this activity improved my understanding of how cloud engineers compare cloud platforms and make decisions based on technical and business requirements.
