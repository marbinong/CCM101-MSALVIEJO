# Microsoft Azure Research

## Brief Overview

**Microsoft Azure** is Microsoft's public cloud platform. It provides services for computing, storage, databases, networking, identity, analytics, artificial intelligence, containers, and application development.

Azure is especially useful for organizations that already use Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, SQL Server, and .NET.

Microsoft announced Windows Azure in 2009, and it became generally available in 2010.

## Global Infrastructure

Azure uses a worldwide network of geographic regions and availability zones.

Organizations can choose Azure regions based on latency, data residency, compliance, and application requirements.

Azure Availability Zones are physically separated locations within an Azure region. They can improve application availability by distributing resources across separate zones.

Official source:

https://learn.microsoft.com/azure/reliability/availability-zones-overview

## Cloud Management Console

The **Azure portal** is a web-based console used to create, manage, monitor, and configure Azure resources.

It provides access to virtual machines, databases, networking, security, monitoring, and cost management.

Official source:

https://learn.microsoft.com/en-us/azure/azure-portal/azure-portal-overview

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual machines for Linux and Windows workloads.

They are useful when an organization needs control over the operating system and software environment.

### 2. Azure Blob Storage

Azure Blob Storage is object storage designed for large amounts of unstructured data such as documents, images, videos, backups, and application data.

### 3. Azure Virtual Network

Azure Virtual Network provides private networking for Azure resources. It supports IP addressing, subnets, routing, and secure connectivity.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service.

It supports authentication, access control, and protection for users, applications, devices, and resources.

## Three Advantages

1. **Strong Microsoft integration** – Azure works closely with Windows Server, Microsoft 365, SQL Server, .NET, and Microsoft Entra ID.
2. **Hybrid cloud support** – Azure provides tools for connecting on-premises infrastructure with cloud resources.
3. **Enterprise capabilities** – Azure provides services for security, compliance, governance, monitoring, and large-scale applications.

## Typical Enterprise Use Cases

Azure is commonly used for:

- Windows Server migration
- Microsoft 365 and identity integration
- Enterprise application hosting
- SQL Server workloads
- Hybrid cloud infrastructure
- Virtual desktops
- Business applications
- Containerized applications
- Artificial intelligence and analytics
