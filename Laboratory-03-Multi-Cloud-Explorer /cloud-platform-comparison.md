# Cloud Platform Comparison

## Major Cloud Platform Comparison

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity Service | AWS IAM | Microsoft Entra ID | Cloud IAM |
| Primary Strength | Broad service portfolio and global infrastructure | Microsoft ecosystem and enterprise integration | AI/ML, data, and Kubernetes |
| Ideal Organizations | Startups, enterprises, and global applications | Microsoft-based enterprises and hybrid environments | AI/data-focused and cloud-native organizations |

## Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** is a strong choice for the broadest overall service portfolio. It offers services across compute, storage, databases, networking, security, analytics, artificial intelligence, and many other categories.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** is the best choice for organizations that already depend heavily on Microsoft technologies. Azure integrates closely with Windows Server, Microsoft 365, Microsoft Entra ID, SQL Server, and .NET.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud** is a strong choice for AI/ML and Kubernetes-focused workloads. Google Cloud provides extensive AI and data services, while GKE provides managed Kubernetes.

### 4. Which cloud platform would you personally choose and why?

**I would personally choose AWS** because it provides a broad selection of services and gives organizations many options for building and scaling applications. Its global infrastructure and large service portfolio make it a flexible choice for different workloads.

| Kubernetes | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Service Explanation

### Virtual Machine

Virtual machine services allow organizations to run operating systems and applications in cloud-based virtual servers.

### Object Storage

Object storage is used to store files, images, videos, backups, and other unstructured data.

### Identity Management

Identity services manage users, authentication, authorization, and access to cloud resources.

### SQL Database

Managed SQL database services provide relational databases without requiring the organization to manage all database infrastructure manually.

### Kubernetes

Managed Kubernetes services help organizations deploy, manage, and scale containerized applications.
