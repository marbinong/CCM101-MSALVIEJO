# Client Recommendations

## Checkpoint 4 – Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: Google Cloud

Google Cloud is a good choice for a startup that wants to launch a mobile application while controlling costs and preparing for future growth. The company can use managed and serverless services so that it does not need to manage every part of the infrastructure manually. Google Cloud also provides scalable compute and storage services that can grow as application traffic increases.

### Possible Services

- Google App Engine
- Cloud Run
- Cloud Storage
- Cloud SQL
- Firebase

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is the strongest choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Microsoft Entra ID can provide cloud identity and access management while supporting integration with the Microsoft environment. Azure Virtual Machines can host Windows or Linux workloads, while Azure also provides services that support hybrid environments.

### Possible Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Virtual Network
- Azure SQL Database
- Azure Backup

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

Google Cloud is recommended because the company focuses on artificial intelligence and machine learning workloads. Google Cloud provides AI and machine learning services, specialized computing resources, and strong data-processing capabilities. Compute Engine can provide GPU-enabled infrastructure, while Google Cloud AI services can support model development and deployment.

### Possible Services

- Compute Engine
- Vertex AI
- Cloud Storage
- BigQuery
- Google Kubernetes Engine

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a strong choice for a multinational e-commerce company because it provides global infrastructure and many services for highly available and scalable applications. The company can distribute workloads across multiple Availability Zones and use load balancing and automatic scaling to handle changes in demand. AWS also provides managed database, storage, networking, and content delivery services.

### Possible Services

- Amazon EC2
- Elastic Load Balancing
- Amazon EC2 Auto Scaling
- Amazon RDS
- Amazon S3
- Amazon CloudFront

# Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | Google Cloud | Good support for serverless, managed services, rapid development, and scalable applications. |
| Enterprise Organization | AWS | Broad service portfolio and mature infrastructure for complex enterprise workloads. |
| Microsoft Environment | Azure | Strong integration with Windows Server, Microsoft 365, Microsoft Entra ID, SQL Server, and other Microsoft technologies. |
| AI / Machine Learning | Google Cloud | Strong AI/ML services, data tools, GPUs/TPUs, and machine learning capabilities. |
| Kubernetes Deployment | Google Cloud | GKE provides managed Kubernetes with strong Google expertise in container orchestration. |
| Global Web Application | AWS | Global infrastructure and services for load balancing, scaling, storage, databases, and content delivery. |

## Final Recommendation Summary

There is no single cloud provider that is automatically best for every organization.

The best choice depends on the client's existing technology, budget, technical requirements, location, compliance needs, and future growth.

- **AWS:** Best overall flexibility and broad service selection.
- **Azure:** Best for Microsoft-centered organizations and hybrid environments.
- **Google Cloud:** Best for AI/ML, data analytics, and Kubernetes-focused workloads.
